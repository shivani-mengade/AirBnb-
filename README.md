# AirBnb
## NYC Airbnb Data Exploration & Analysis
## Description
This project is a Python-based data analysis and visualization of Airbnb listings in New York City. It leverages pandas, NumPy, seaborn, and matplotlib to explore a dataset of approximately 20,770 listings,
examining key features such as price, number of reviews, room types, and geographic location (neighborhood).

## Motivation
The goal of this project is to uncover insights into the NYC Airbnb market: how prices are distributed, which boroughs or neighborhoods are more expensive, and how review count relates to pricing. 
This analysis could help prospective Airbnb hosts or guests better understand pricing trends and market behavior.


Cleans and preprocesses the raw dataset (drops duplicates, handles data types)

Visualizes price distribution using boxplots and histograms

Compares average prices across different NYC boroughs (neighborhood groups)

Investigates correlations between price, number of reviews, minimum nights, and availability through scatter plots and pair plots

## Key Findings

Most Airbnb listings fall under a certain price range, with a long tail of higher-priced listings

Manhattan listings tend to have higher average prices compared to other boroughs

There’s a noticeable (though not strictly linear) relationship between review count and price many high-priced listings don’t necessarily have more reviews
